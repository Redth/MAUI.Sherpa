## 🏔️ v0.13.2 — "Securing the Mac Route"

We're making one more quick repair at camp after v0.13.1. This patch replaces a faulty anchor
in the macOS release path so Apple Silicon climbers can open MAUI Sherpa without dyld stopping
the expedition before it begins.

### 🐛 Bug Fixes

- **Apple Silicon Launch Restored** — The macOS app now repairs the Copilot runtime's
  build-machine load command before signing, preventing the immediate startup crash seen in
  v0.13.0 and v0.13.1. (#234)

### 🔧 Infrastructure

- **Native Dependency Guardrails** — Release builds now reject machine-specific paths,
  duplicate dylib load commands, and unresolved non-system dependencies before the macOS
  artifact is signed and published.

---

*The anchor is reset, the route is checked, and the Mac team can keep climbing.* 🧗
