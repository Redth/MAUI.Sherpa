## 🏔️ v0.16.3 — "Retightening the Anchors"

One more anchor check before moving farther along the ridge. This release brings
the merged macOS toolbar fixes together with the Apple sign-in, profiling, and
signing-tool improvements prepared for the previous patch releases.

### ✨ Improvements

- **Apple's Own Sign-In Trail** — On macOS, Apple Developer sign-in opens Apple's
  web flow inside Sherpa by default, supporting passkeys, Touch ID, and Apple's
  verification prompts where available; the Apple ID and password form remains
  a click away.
  ([#285](https://github.com/Redth/MAUI.Sherpa/pull/285))
- **One Bundle ID, Both Routes** — Choose **Universal** when registering an Apple
  bundle ID, alongside iOS and macOS; the Copilot `create_bundle_id` tool supports
  the same option.
  ([#274](https://github.com/Redth/MAUI.Sherpa/pull/274))

### 🐛 Bug Fixes

- **A Steadier Grip on the Toolbar** — macOS toolbar actions keep stable commands
  while their labels, visibility, and enabled state follow the active page.
  Navigation updates are coalesced, filter changes no longer rebuild the entire
  toolbar, and inactive or disabled actions are ignored.
  ([#286](https://github.com/Redth/MAUI.Sherpa/pull/286))
- **Apple Sessions That Keep Their Footing** — Restored and imported sessions send
  cookies to the correct Apple subdomains, while remembered account details and
  two-factor trust survive an expired web session. Account-lock errors show
  recovery guidance instead of masquerading as an incorrect password.
  ([#285](https://github.com/Redth/MAUI.Sherpa/pull/285))
- **Live Profiling Back on the Rope** — Fixed Profiling-tab startup, session
  discovery, and timeline parsing against current DevFlow agents, restoring live
  charts and stop/restart flows. Apps without profiling enabled report their
  actual availability.
  ([#282](https://github.com/Redth/MAUI.Sherpa/pull/282))
- **Inspector Controls That Reach the App** — Corrected DevFlow request framing
  so control-lease claims, property edits, actions, and WebView mutations no longer
  fail with connection errors against current agents.
  ([#282](https://github.com/Redth/MAUI.Sherpa/pull/282))
- **Windows Keystore Imports, Unblocked** — Restored the masked password prompt,
  detect the actual keystore type and signing aliases rather than guessing from
  the filename, and offer an alias choice when multiple keys are present. Import
  failures surface the underlying error instead of blaming every stumble on the
  password.
  ([#283](https://github.com/Redth/MAUI.Sherpa/pull/283))
- **Doctor, One Fix at a Time** — Conflicting fixes stay disabled while an
  operation is preparing or running; an already-open process window gets a clear
  close-and-retry message without disturbing the active operation.
  ([#284](https://github.com/Redth/MAUI.Sherpa/pull/284))
- **A Clear First Step for Service Accounts** — Fixed the identity picker so a
  service-account identity can be selected even when none has been added before.
  ([#277](https://github.com/Redth/MAUI.Sherpa/pull/277))

### 🔧 Infrastructure

- **Refreshed Gear** — Updated to .NET SDK **10.0.402**, refreshed DevFlow and Linux
  GTK packages, and updated supporting dependencies. The DevFlow refresh also
  fixes the missing `chobitsu.js` asset that blocked Windows Debug builds.
  ([#280](https://github.com/Redth/MAUI.Sherpa/pull/280),
  [#281](https://github.com/Redth/MAUI.Sherpa/pull/281),
  [#284](https://github.com/Redth/MAUI.Sherpa/pull/284))
- **Stay on the Marked SDK Trail** — SDK selection stays on stable .NET 10 feature
  bands rather than rolling forward to an installed .NET 11 preview.
  ([#274](https://github.com/Redth/MAUI.Sherpa/pull/274))
- **Cross-Platform Anchor Check** — Retains the release-build corrections from
  v0.16.2 for the shared Apple sign-in page on Windows and Linux, and native
  header-button layout on macOS.
