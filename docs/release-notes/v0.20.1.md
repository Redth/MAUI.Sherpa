## 🏔️ v0.20.1 — "Securing the Pack"

Good gear still needs to be packed correctly. **v0.20.1 replaces the withdrawn v0.20.0**
and fixes the immediate startup crash in its downloadable macOS app, while keeping the new
Android tooling, refreshed desktop interface, and .NET 11 foundation.

### 🐛 Bug Fixes

- **macOS Downloads Back on Their Feet** — The universal app now finds the correct
  architecture-specific .NET assemblies during startup instead of aborting before its
  first window opens.
- **A Check Before the Pack Leaves Base Camp** — Release CI now starts the packaged macOS
  app after signing and rejects downloads that exit during startup.
- **Copilot Finds Another Route** — An incompatible installed Copilot CLI can fall back
  to Sherpa's bundled runtime instead of failing to connect.
  ([#330](https://github.com/Redth/MAUI.Sherpa/pull/330))

### 🆕 New Features Since v0.19.1

- **One Base Camp for Android Tools** — The **SDK & JDK** page brings SDK discovery,
  installation, switching, package management, and Microsoft OpenJDK management together.
  Java 21 is recommended for Android, and available JDK updates appear in the app.
  ([#325](https://github.com/Redth/MAUI.Sherpa/pull/325),
  [#328](https://github.com/Redth/MAUI.Sherpa/pull/328))
- **A Safer Route to Terminal Tools** — Preview and explicitly apply PATH updates so
  commands like `adb` and `emulator` use your chosen SDK; switching SDKs alone does not
  change your shell configuration. ([#325](https://github.com/Redth/MAUI.Sherpa/pull/325))
- **Better-Packed Push Projects** — Dedicated APNs and Firebase project dialogs support
  saved identities, credential files, pasted credentials, and available managed secrets.
  Pasted credentials stay in Local Vault, and JSON payloads get validation and formatting.
  ([#330](https://github.com/Redth/MAUI.Sherpa/pull/330))

### ✨ Improvements

- **A Clearer Trail on Every Desktop** — Pages, dialogs, and inspectors share refreshed
  controls and light/dark themes that feel at home on macOS, Windows, and Linux.
  ([#330](https://github.com/Redth/MAUI.Sherpa/pull/330))
- **Less Shuffling, More Selecting** — Bulk selection stays in the heading without moving
  the list, with new batch actions for bundle IDs, registered Apple devices, and secrets.
  ([#330](https://github.com/Redth/MAUI.Sherpa/pull/330))
- **A Tidier Dashboard and Tool Inventory** — Inspect Doctor issues more easily, see
  installed .NET SDKs alongside their workload bands, configure the .NET tools NuGet feed,
  and follow or cancel OpenJDK downloads.
  ([#330](https://github.com/Redth/MAUI.Sherpa/pull/330))

### 🔧 Infrastructure

- **A .NET 11 Foundation** — Updated MAUI macOS and Linux GTK backends, DevFlow packages,
  and build tooling underpin this next stretch of the trail.
  ([#326](https://github.com/Redth/MAUI.Sherpa/pull/326))

*Pack secured, footing checked, and the same mountain ahead.* 🥾
