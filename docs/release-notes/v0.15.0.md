## 🏔️ v0.15.0 — "Roping Up the Team"

No serious ascent depends on a single anchor. This release ropes MAUI Sherpa's secret
providers together, letting every certificate, keystore, profile, and managed secret travel
with the cloud services that fit the route — while background tasks keep the whole team moving.

### 🆕 New Features

- **Multi-Provider Secret Sync** — Choose one or more destinations per item across Local Vault,
  Azure Key Vault, AWS Secrets Manager, Google Secret Manager, Infisical, 1Password,
  Vaultwarden, and Azure DevOps, with configurable defaults and conflict-aware reconciliation.
  (#239)
- **Background Task Center** — Follow sync progress by provider, retry failures, cancel work,
  and recover interrupted jobs after restart without storing secret payloads in task history.
  (#239)
- **Broader Apple Publishing Workflows** — Create every certificate type supported by App Store
  Connect, install and sync new identities automatically, and publish with multiple signing
  certificates and provisioning profiles. (#240)
- **Multi-Certificate P12 Export** — Select several local signing identities and export one
  protected P12 bundle to disk, Base64 clipboard, or both. (#242)

### ✨ Improvements

- **Safer Provisioning Profile Maintenance** — Regeneration now preflights App Group
  entitlements, downloads replace matching profiles atomically, and a new cleanup review finds
  expired, unreadable, superseded, and certificate-orphaned profiles before anything is
  removed. (#245)
- **Faster Infisical Writes** — Update-first upserts, shared authentication, native metadata,
  and batched inventory reads eliminate costly missing-secret retries while preserving
  transactional rollback. (#244)

### 🐛 Bug Fixes

- **Windows Device Tools** — Registered the missing deep-link validation service so opening
  device tools no longer crashes the Blazor UI on Windows. (#243)

### 🔧 Infrastructure

- **Updated MAUI DevFlow Kit** — Advanced the DevFlow packages to preview 12 and refreshed the
  project's onboarding, debugging, and session-review guidance. (#246)

*The rope team is tied in, the anchors are sound, and the next ridge is calling.* 🧗
