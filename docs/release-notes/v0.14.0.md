## 🏔️ v0.14.0 — "Opening the Windows Route"

This stage of the expedition clears a better trail for Windows climbers. MAUI Sherpa now
offers a more readable toolbar and proper self-contained installers, making the route from
download to Start menu much easier to follow.

### 🆕 New Features

- **Windows Installers** — Self-contained x64 and ARM64 installers now add MAUI Sherpa to the
  Start menu and provide standard per-user uninstall support, while ZIP downloads remain
  available for existing update flows. (#235)

### ✨ Improvements

- **Clearer Windows Toolbar** — Toolbar actions now pair centered Fluent icons with readable
  labels such as Release Notes, New Folder, and Open Project Folder, with correct mappings and
  enabled states throughout. (#235)

### 🔧 Infrastructure

- **Smoother WinGet Handoff** — WinGet manifests now target the new installers, and release
  automation provides maintainers with a prefilled browser submission link instead of relying
  on short-lived SSO authorization. (#235)

---

*The Windows route is marked, packed, and ready for the next ascent.* 🧭
