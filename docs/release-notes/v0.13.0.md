## 🏔️ v0.13.0 — "Repacking for the Next Ascent"

The route ahead is clearer, and this release reorganizes the expedition around the tools that
matter most on the climb. MAUI Sherpa now offers a stronger development environment dashboard,
a rebuilt profiling trail powered by the MAUI CLI, and steadier recovery when SDK or publishing
conditions change beneath your feet.

### 🆕 New Features

- **Development Environment Dashboard** — A new dashboard brings SDK health, tool status, release
  notes, and common actions into one basecamp view, with a streamlined toolbar for faster access.
  (#213, #227)
- **MAUI CLI Profiling** — App profiling has been rebuilt on the MAUI CLI with guided capture,
  artifact recovery, session history, prerequisites, and diagnostics gathered into a clearer
  end-to-end workflow. (#221)
- **In-App Release Notes** — A dedicated dialog now highlights what changed after an update, so
  climbers can check the latest trail markers without leaving the app. (#213)

### ✨ Improvements

- **Smarter .NET Tooling** — Doctor and SDK management now treat the `dotnetup` root as
  authoritative, support interactive prompts, understand preview SDKs, and recover gracefully
  when workload-set metadata is unavailable. (#218, #222, #226, #229)
- **Expanded Copilot Models** — Copilot model selection now recognizes the latest available models,
  while improved recovery and external navigation make interrupted routes easier to resume.
  (#211, #214, #227)
- **Lean Windows Packaging** — Windows releases now center deployment on a self-contained
  executable alongside the app's required web assets, simplifying the route from download to
  launch. (#210)

### 🐛 Bug Fixes

- **Profiling Navigation** — Opening profiling on Windows no longer crashes during navigation.
  (#228)
- **SDK Uninstall Resolution** — SDK removals now resolve the correct managed channel instead of
  losing the trail between installed versions. (#209)
- **Publishing Credentials** — Certificate secrets are resolved correctly during publish, keeping
  signing workflows moving when credentials come from synchronized stores. (#230)

### 🔧 Infrastructure

- **Automated Distribution** — Stable releases can now submit updated WinGet manifests
  automatically, while Homebrew setup guidance points macOS users to the correct dependencies.
  (#207, #208)
- **Fresh Expedition Kit** — The repository moved to .NET SDK 10.0.302 and refreshed its grouped
  NuGet dependencies for the next stretch of the climb. (#215, #216, #220, #225)

---

*The pack is balanced, the route is marked, and the next ascent is ready to begin.* 🧗
