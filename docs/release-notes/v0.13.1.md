## 🏔️ v0.13.1 — "Retightening the Download Rope"

We're staying at the same camp for a quick gear check after v0.13.0. This patch secures the
update route against temporary GitHub network failures and makes sure climbers always have a
clear way to retry or download the release manually.

### 🐛 Bug Fixes

- **Resilient App Updates** — Update downloads now retry transient GitHub failures with bounded
  connection timeouts, reject incomplete archives, and preserve the original failure in the logs
  for diagnosis.
- **Recoverable Update Dialog** — Failed updates now offer **Retry** and **Open Release Page**
  actions instead of stranding the user on a raw network error.
- **Reliable Manual Downloads** — The manual download action is labeled clearly and no longer
  silently closes the dialog when macOS cannot open the release page.

### 🔧 Infrastructure

- **WinGet Publishing Authentication** — Release automation now publishes manifests with a deploy
  key and handles accepted validation warnings consistently. (#231)

---

*The rope is tight, the backup route is marked, and the team can keep moving.* 🧗
