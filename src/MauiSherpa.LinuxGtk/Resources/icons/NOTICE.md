# Linux symbolic icons

These icons are registered with the GTK icon theme by `LinuxIconTheme`. Names ending in
`-symbolic` are recolored by GTK to match the active light or dark theme.

- `sherpa-copilot-symbolic.svg` is the `copilot-16` icon from
  [GitHub Octicons](https://github.com/primer/octicons), MIT License, Copyright GitHub Inc.
- All other icons are glyphs from Font Awesome Free 6.5.1 (`wwwroot/vendor/fontawesome`),
  [CC BY 4.0](https://fontawesome.com/license/free), Copyright Fonticons, Inc.
